# 湖畔小鎮鐵道 · Alpine Lake Town Railway

以 Three.js 程式生成的低多邊形（low-poly）場景：日落時分的高山湖畔，湖邊有一座瑞士木屋風格的小鎮，蒸汽火車沿著湖岸從一座隧道開到另一座隧道，中途進站停靠。

所有模型、貼圖和音效都在瀏覽器裡即時產生，不需要任何外部素材，也不需要建置步驟。

## 功能

- **地形**：用 fbm 雜訊產生山脈與丘陵，另外有湖泊、溪流，以及沿著鐵路整平的路基
- **鐵路**：鋼軌、枕木、道碴、木造棧橋、兩座隧道口、月台雨棚、平交道、水塔、號誌
- **蒸汽火車**：2-6-0 機車、煤水車、三節客車
  - 動輪、連桿、十字頭依行駛距離連動，左右兩側相位差 90°
  - 每節車廂用兩個轉向架點定位在軌道上，過彎時沿著軌道走
  - 進站依 `v² = 2as` 減速，停靠 12 秒後出站
  - 煙囪排煙和動輪轉動同步，起步時汽缸會排出白色蒸汽
- **小鎮**：參數化的瑞士木屋產生器，另外有車站、旅館、教堂、廣場噴泉、碼頭與小船、街燈
- **時段**：日落 → 藍調時刻 → 夜晚，天色、霧、光線平滑過渡；夜晚有星空、銀河、月光、流星和螢火蟲，窗戶會分批亮燈
- **鏡頭**：自由視角、跟車、駕駛室、自動導覽
- **音效**：用 Web Audio 即時合成汽笛、排氣聲和營火聲，點「音效」按鈕後才會播放

## 執行

這個專案使用 ES modules，必須透過 HTTP 伺服器開啟，直接雙擊 `index.html` 無法執行。

```bash
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000
```

three.js r170 會從 jsDelivr CDN 載入，所以第一次開啟時需要連網。

### GitHub Pages

1. 進入 repo 的 **Settings → Pages**
2. **Source** 選 `Deploy from a branch`，分支選 `main`，資料夾選 `/ (root)`
3. 幾分鐘後就可以在 `https://jiaming7674.github.io/alpine-lake-town/` 瀏覽

## 專案結構

```
index.html          頁面、樣式、控制面板、importmap
js/
├── main.js         進入點：建立場景、串起各模組、主迴圈
├── core.js         共用設定、數學工具、GeoBag（合併靜態幾何）、材質
├── route.js        軌道路線、街道、溪流、距離格網
├── world.js        地形高度函數 heightAt()、軌道坡度
├── terrain.js      地形網格、湖面（Water.js）
├── sky.js          天空、日月光源、夜空、時段系統、跟隨鏡頭的陰影範圍
├── nature.js       樹林、花草、螢火蟲
├── cabin.js        木屋、風車、石板小徑、營火
├── smoke.js        共用的煙霧粒子池（InstancedMesh）
├── railway.js      鋼軌、枕木、棧橋、隧道口、月台、水塔、號誌
├── train.js        蒸汽火車、連桿機構、運行狀態機
├── town.js         木屋產生器、車站、教堂、碼頭、街燈
├── cameras.js      四種鏡頭模式
├── audio.js        Web Audio 合成音效
├── post.js         God rays、Bloom、景深、輸出
└── ui.js           控制面板元件
```

### 相依關係

```
core.js ← route.js ← world.js ← terrain / nature / cabin / railway / town / cameras
smoke.js ← cabin / train / town
audio.js ← train
```

- `route.js` 定義軌道與街道的位置，並建立距離格網；地形整地、樹木避讓、建築配置都依賴它。
- `world.js` 的 `heightAt(x, z)` 是整個場景唯一的高度來源。
- 靜態物件用 `GeoBag` 依材質合併，整個小鎮只佔 2 次繪製呼叫。

## 操作

| 操作 | 桌機 | 手機 |
|---|---|---|
| 旋轉 | 滑鼠左鍵拖曳 | 單指拖曳 |
| 縮放 | 滾輪 | 雙指捏合 |
| 平移 | 滑鼠右鍵拖曳 | 雙指拖曳 |

右下角的面板可以切換時段、鏡頭模式、火車速度、風速、營火強度，以及 Bloom 和 God rays 的強度。

## 技術重點

- **單一陰影範圍跟著鏡頭移動**：沒有使用 CSM，因為它會覆蓋材質的 `onBeforeCompile`，和樹木擺動、煙霧透明度、窗戶亮燈這三個自訂 shader 衝突。陰影範圍會依鏡頭距離縮放，並對齊陰影貼圖的像素格線，減少移動時的閃爍。
- **湖面反射**：花草、枕木、連桿等小物件放在另一個 layer，不畫進反射，降低成本。
- **手機**：會自動降低像素比、陰影解析度，以及樹木和粒子的數量。
